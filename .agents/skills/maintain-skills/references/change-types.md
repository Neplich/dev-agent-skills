# Skill Changes

## Add

Create `agents/{role}/skills/{name}/SKILL.md` with a matching `name` and useful `description`. Add references and tools as needed. Register the path, update capability directories and refresh the lockfile. A new plugin also supplies bilingual READMEs, its manifest and distribution registration.

## Modify

Update the relevant method, script or reference. Align discovery descriptions and examples with changed behavior. Refresh content hashes for modified Skill directories and regenerate affected shared references.

## Rename

Move the directory and update its frontmatter name, marketplace path, lockfile entry, capability directories and local references together. Search for the previous path and run the relevant installation and link checks.
