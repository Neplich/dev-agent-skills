# 生产力应用落地页

## 目标

让知识工作者在一次滚动浏览中理解产品价值、核心工作流和开始使用的入口。

## 已确认信息结构

- 顶部导航、主价值主张和单一主要 CTA。
- 工作流或核心能力的渐进式说明。
- 界面预览、集成或协作证明。
- 信任信息与最终 CTA。

## 交互与响应式要求

- 桌面端保持克制的导航和清晰章节节奏。
- 移动端折叠导航、纵向堆叠内容并保持主要 CTA 可见。
- 动效只用于解释状态转换或引导阅读，不用于装饰。
- 表单或 CTA 需要明确的 focus、loading、success 和 error 反馈。

## 参考边界

可以借鉴 Linear 的信息层级、内容节奏和产品证明方式；不得复制其品牌、文案、插图、截图或产品命名。
