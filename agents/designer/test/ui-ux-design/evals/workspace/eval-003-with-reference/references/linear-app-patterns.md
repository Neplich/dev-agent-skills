# Linear 首页参考模式

- Reference URL: https://linear.app/
- Verified: 2026-07-26
- Evidence method: Chrome 可见页面结构核验

## 可借鉴模式

- 克制的顶部导航，将 Product、Resources、Customers、Pricing 与主 CTA 分开。
- 单一主标题与简短副标题建立首屏叙事，主 CTA 优先。
- 先展示真实产品界面，再用连续章节逐步解释 Intake、Plan、Build、Diffs、Monitor 等能力。
- 章节使用编号、短标题、产品预览和明确的深层链接形成阅读节奏。
- 交互展示服务于产品工作流说明，信息层级和留白优先于装饰。
- 移动端应折叠导航、保持 CTA 清晰，并将产品证明按阅读顺序纵向排列。

## 禁止照搬

- 不复制 Linear 品牌、文案、截图、图标、产品名称或视觉资产。
- 不把参考站当前产品功能当作本产品需求。
- 参考结论是当前设计阶段的稳定输入；后续重新调研时应记录新的核验日期。
