# 手工艺品商店

## 当前状态

产品范围已确认，当前需要形成移动端优先的商品发现与购物车设计。

## 目标用户

主要用户通过手机浏览独立创作者的手工艺品，关注图片、材质、价格、库存与配送提示。

## 已确认范围

- 商品列表、分类和可收起筛选。
- 商品详情页及图片、规格、库存和加入购物车反馈。
- 购物车中的数量调整、移除和价格汇总。
- 加载、空结果、筛选无结果、缺货和购物车为空状态。

## 验收期望

- 从列表到购物车的主要路径可单手完成，关键操作触控目标不小于 44px。
- 筛选状态可见、可清除，返回列表时保留选择。
- 加入购物车、数量变更与错误均提供明确反馈。
- 桌面布局可扩展，但不得牺牲 mobile-first 信息优先级。
