# Eval 1: SaaS Dashboard Design Structure

This workspace simulates a spec-backed design request:

- PM has already produced `docs/pm/saas-dashboard/PRD.md` for a project
  management dashboard
- Designer should read the PM spec, produce a structured UI/UX handoff doc
  under `docs/design/saas-dashboard/`, and stop at the design handoff
- Designer must not start implementation work

The regression target is twofold: producing unstructured or vague design
notes instead of the canonical spec, and crossing the Designer-Engineer
boundary after reading the PM spec.
