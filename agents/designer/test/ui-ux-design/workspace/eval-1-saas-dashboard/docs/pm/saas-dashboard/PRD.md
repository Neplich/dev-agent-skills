# PRD: SaaS Dashboard

## Goal

Give small teams (5-20 people) a single project management dashboard where
they can see projects, tasks, team members, and the activity timeline at a
glance.

## User Stories

- As a team member, I want to view all projects and their status so I know
  where work stands.
- As a team lead, I want to see tasks grouped by project and assignee so I can
  spot overloads early.
- As a team member, I want a team member directory with roles so I know who
  owns what.
- As a team lead, I want an activity timeline of recent changes so the team
  stays aligned without meetings.

## Acceptance Criteria

1. The dashboard lists projects with name, status, and progress.
2. Tasks are visible with assignee, due date, and status.
3. Team members are listed with name and role.
4. An activity timeline shows recent project and task changes.
5. The layout stays usable for teams of 5-20 people on desktop and tablet.
