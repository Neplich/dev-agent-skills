# 企业分析平台

## 目标用户

分析师、运营负责人和管理层在桌面端查看高密度仪表盘、表格、图表和告警。

## 视觉目标

- 可信、权威、克制，适合长时间阅读。
- 数据层级清晰，状态、筛选和关键指标易于扫描。
- 颜色承担明确语义，但任何状态都不能只靠颜色区分。

## 可访问性要求

- 普通文本对比度至少 4.5:1。
- 大文本与关键 UI 边界对比度至少 3:1。
- 焦点状态清晰，键盘导航不依赖 hover。
- disabled、loading、empty、error 和 warning 状态必须可区分。

## 范围

视觉系统覆盖颜色、字体、间距、表格、图表、筛选、按钮、输入、状态和告警；不包含组件实现或样式文件修改。
