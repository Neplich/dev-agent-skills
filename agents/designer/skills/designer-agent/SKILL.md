# Product Design

Use design knowledge for the user's requested artifact, from an interaction
explanation or visual specification to an implemented interface. Inspect the
existing product, audience, content, and design system before choosing changes.

| Focus | Reference |
| --- | --- |
| Journeys, information architecture, and interaction | [UI/UX design](../ui-ux-design/SKILL.md) |
| Visual language, typography, color, and component treatment | [Visual design](../visual-design/SKILL.md) |

Choose the detail and artifact format that help the task. Combine design,
implementation, and verification when the request spans them. Use available
browser tools to inspect actual layouts and interaction states for implemented
work. Explain important choices through the user's goal and product context.
