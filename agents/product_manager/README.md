# Product Manager Skills

This plugin provides 9 skills for requirements, catalogs, research, roadmaps, release communication and writing. Every skill can be used directly; `pm-agent` helps select relevant methods for a task.

The assistant combines capabilities to complete the user's goal through analysis, implementation, validation and delivery. Authorization carries through the task, and documents and references are selected as needed.

## Skills

| Skill | Purpose |
| --- | --- |
| [pm-agent](./skills/pm-agent/SKILL.md) | Product capability guide |
| [idea-to-spec](./skills/idea-to-spec/SKILL.md) | Requirements and acceptance criteria |
| [feature-catalog](./skills/feature-catalog/SKILL.md) | Feature catalogs from existing projects |
| [competitive-brief](./skills/competitive-brief/SKILL.md) | Competitive research and positioning |
| [changelog-gen](./skills/changelog-gen/SKILL.md) | Developer changelogs |
| [github-release-gen](./skills/github-release-gen/SKILL.md) | GitHub Release preparation and publication |
| [roadmap-gen](./skills/roadmap-gen/SKILL.md) | Roadmaps and milestones |
| [github-reader](./skills/github-reader/SKILL.md) | GitHub project status |
| [human-writing](./skills/human-writing/SKILL.md) | Natural, reader-oriented writing |

## Installation and Use

```text
/plugin install pm-agent@dev-agent-skills
```

The [Codex guide](../../docs/README.codex.md) installs all skills. Describe the goal or name a skill directly.
