# idea-to-spec

将产品想法和功能变更整理为清晰目标、范围与可验证要求。用户请求、issue、代码、测试和已有文档均可作为起点；当前助手按任务需要选择专业资料并完成授权工作。

入口见 [SKILL.md](SKILL.md)。[资料索引](_internal/_shared/skill-map.md) 收录生成、修订、分析和校验方法；[文档格式](_internal/_shared/output-conventions.md) 与 [schema](_internal/_shared/doc-schemas/prd-schema.md) 用于需要长期维护的规格。

`_internal/` 按主题存放可选参考，`gen/` 提供编写方法，`iteration/` 提供增量修订方法，`analysis/` 提供影响和一致性分析，`validator/` 提供质量检查。
