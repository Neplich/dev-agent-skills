# ADR 编写参考

记录需要长期保留的技术决定：背景、采用方案、主要取舍、后果和支持证据。引用相关实现、评测和文档。决策背景保留影响后续维护的事实，当前正文清晰表达所采用的方案。工程设计参考 `engineer-agent:trd-gen`。

读取当前请求及相关证据，选择适合交付物的章节，完成编写后核对事实、术语、链接与可验证性。已有文件沿用稳定路径和有效格式，更新受影响内容。

模板参考 [schema](../../_shared/doc-schemas/adr-schema.md)，格式参考 [output-conventions.md](../../_shared/output-conventions.md)。
