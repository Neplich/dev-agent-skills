# TSPECS 编写参考

根据用户要求、issue、实现和现有测试定义覆盖范围。优先复用已有用例，补足关键主流程、异常、权限和边界验证。每个用例写出前置状态、输入步骤和可观察结果，区分计划执行与真实执行结果。持久 E2E 用例沿用宿主目录与稳定 ID。

读取当前请求及相关证据，选择适合交付物的章节，完成编写后核对事实、术语、链接与可验证性。已有文件沿用稳定路径和有效格式，更新受影响内容。

模板参考 [schema](../../_shared/doc-schemas/test-spec-schema.md)，格式参考 [output-conventions.md](../../_shared/output-conventions.md)。
