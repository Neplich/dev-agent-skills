# 功能盘点

根据用户要求确定盘点范围。阅读入口、路由、界面、权限、领域模型、配置、测试和已有文档，将功能组织为用户可以理解的任务与结果。

以实现和验证证据区分已支持能力、目标范围和待核实项。已有稳定功能路径可以复用；新索引按实际维护边界组织。功能目录适用于全局盘点和长期维护，普通局部任务可直接输出相关发现。

需要持久目录时，使用 [盘点参考](_internal/INSTRUCTIONS.md)，在授权范围内同步索引、链接与相关说明。完成后给出覆盖范围、可追溯功能清单及关键缺口。
