# GitHub Release

从用户请求确定预览、草稿、更新或发布目标。读取仓库发布规范、版本范围和当前 GitHub 状态，完成授权范围内的工作。发布内容可来自站内 Release Notes、changelog、PR 和可达提交，统一核对到同一版本。

发布及标签动作沿用用户设定的权限，已有授权在整个任务中持续适用。需要新授权时先准备完整可审阅内容和执行目标，再说明具体请求。

内容参考 [发布结构](reference/release-outline.md)，GitHub 操作参考 [发布方法](reference/github-release-workflow.md)。完成后回读实际状态，交付发布地址、版本、资产与验证结果。
