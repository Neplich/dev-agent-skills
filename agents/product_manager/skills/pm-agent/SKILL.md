# 产品能力入口

从用户目标和已有证据出发，选择有帮助的方法与模板。当前助手负责把已授权的任务推进到可验证结果；任务范围、已有决策和授权在使用不同专业资料时持续有效。

| 任务 | 参考 |
| --- | --- |
| 需求梳理、产品方案、PRD | [idea-to-spec](../idea-to-spec/SKILL.md) |
| 功能盘点 | [feature-catalog](../feature-catalog/SKILL.md) |
| 竞品与定位 | [competitive-brief](../competitive-brief/SKILL.md) |
| 开发者变更记录 | [changelog-gen](../changelog-gen/SKILL.md) |
| GitHub Release | [github-release-gen](../github-release-gen/SKILL.md) |
| 路线图与里程碑 | [roadmap-gen](../roadmap-gen/SKILL.md) |
| GitHub issue、PR、版本状态 | [github-reader](../github-reader/SKILL.md) |
| 读者文稿 | [human-writing](../human-writing/SKILL.md) |

用户请求、issue、实现、测试和已有文档都可以提供工作依据。先消除影响结果的关键歧义，其余采用合理假设并继续。PRD、TRD、计划和独立文档用于需要长期维护、多人协作或复杂决策的任务，按实际价值选用。

需要设计、实现、测试、运维、安全或正式文档方法时，直接使用已有能力和相应资料。工具不可用时尝试适用的替代方式，说明真正缺少的访问、数据或执行能力。完成后交付成果、验证结果以及用户需要知道的剩余事项。
