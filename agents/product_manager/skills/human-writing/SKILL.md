# 自然中文写作

从读者要理解、决定或完成的事情出发，选择材料和组织顺序。用户提供的事实、术语、格式、语气和交付要求优先；专业资料提供写作方法。

1. 确定读者、使用场景、范围和最终交付形式。
2. 用原始材料、已验证的实现与可靠来源支持事实，区分事实、推断和缺口。
3. 按读者任务组织内容，让每段增加有用事实、动作、理由或恢复方式。
4. 保留准确术语、界面文字、代码、命令、字段、路径、引用及真实操作顺序。
5. 写完后核对事实、结构和表达，执行交付物需要的格式或渲染检查。

单段修订聚焦原段；文档集和站点更新先检查页面职责与入口，再改正文。已有授权范围内的组织调整直接完成，并同步链接、图片和导航。

按任务读取 [文档模式](references/document-patterns.md)、[中文表达](references/chinese-prose.md) 或 [修订检查](references/revision.md)。交付读者需要的成稿及实际验证结果。
