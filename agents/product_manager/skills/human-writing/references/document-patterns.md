# 文档组织参考

| 文稿 | 适合的信息顺序 |
| --- | --- |
| 操作手册 | 用户目标、前置条件、入口、动作、可见结果、恢复 |
| 产品说明 | 场景、适用用户、当前行为、权限与限制、结果 |
| PRD | 问题、用户、范围、要求、验收与风险 |
| TRD | 目标与约束、结构、数据流、接口、错误与安全、验证 |
| ADR | 背景、当前决定、必要取舍、后果与依据 |
| API | 目的、接口、鉴权、参数、示例、响应、错误与兼容性 |
| Runbook | 适用条件、权限、步骤、成功信号、恢复和升级处理 |
| QA/审计 | 结论、范围、证据、发现、影响与待办 |
| Release Notes | 行为变化、升级动作、兼容性、修复和限制 |
| README | 项目用途、适用范围、最短安装路径、示例与深入链接 |
| 研究简报 | 决策相关结论、来源、取舍、缺口与建议 |

文档集按读者任务分配页面职责。每项任务有可访问入口，索引帮助定位，正文在适当位置解释事实。移动或合并时保留有效步骤、图片、限制和恢复信息，并核对引用、导航、构建和渲染。
