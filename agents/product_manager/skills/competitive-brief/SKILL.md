# 竞品分析

从用户产品、目标客户与要支持的决策确定研究范围。优先核对竞品官网、文档、定价、发布记录和公开财务资料，再结合可信第三方研究与用户反馈。动态事实记录访问时间，关键结论附直接来源。

| 分析方向 | 核对内容 |
| --- | --- |
| 客户与定位 | 服务谁、解决什么问题、主要使用场景 |
| 产品能力 | 工作流、关键功能、集成、权限和部署方式 |
| 商业模式 | 价格口径、限制、增购项与目标客户 |
| 信息表达 | 核心承诺、差异点、客户证据与渠道 |
| 竞争影响 | 优势、局限、机会、威胁与可执行动作 |

围绕用户决策写分析，区分来源事实、比较推断和证据缺口。比较使用相同时间、版本与适用条件，重点追查会改变建议的差异。

交付可采用简报、能力对照表或销售 battlecard。Battlecard 包含适用场景、对方优势、可证明差异、常见异议与回应依据。建议写明动作、理由、优先级和验证方式。
