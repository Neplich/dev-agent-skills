# 站内发布说明

核对目标版本、代码或标签范围与已交付内容，编写读者需要的功能变化、关键实现、配置迁移、资产和升级说明。版本依据来自用户请求及可核实的仓库发布事实；有实质冲突时询问。

使用宿主既有文档格式与发布结构，在授权范围内同步版本页、索引、metadata 和导航。相关 GitHub 发布操作可直接结合可用能力完成，并沿用用户设定的发布授权。

详见 [执行参考](_internal/INSTRUCTIONS.md)。完成后交付页面、事实来源和验证结果。
