# 文档检查

检查用户指定的页面、变更范围或整套文档。以实现、测试、配置、界面及版本证据核对事实，同时检查 frontmatter、链接、导航和构建。

普通文档检查可直接进行。发布核对使用实际版本与对应代码范围；经过内容验证的页面可以记录相应版本锚。已授权修复可连续完成，审阅请求交付具体发现。

详见 [检查方法](_internal/INSTRUCTIONS.md)。输出检查范围、发现及处理结果、执行证据和真实限制。
