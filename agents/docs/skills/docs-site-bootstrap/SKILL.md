# 文档站脚手架

在用户请求初始化、更新文档站或交付包含站点的范围内使用。读取宿主目录与现有内容，将内置资产安装到 `docs/site/`，并记录 bootstrap manifest。

已有文件按来源和差异判断创建、复用、合并或保留。任务范围内的可逆合并直接完成；覆盖独立用户内容需要明确的任务依据，事实或取舍不足时给出具体差异供用户决定。

[执行参考](_internal/INSTRUCTIONS.md) 说明资产、manifest 与验证方法。完成后报告生成路径、实际保留或修改的内容、检查结果和重复运行状态。
