# 文档能力入口

围绕读者任务和当前事实完成文档工作。用户请求、issue、实现、测试、界面与已有资料均可提供起点；当前助手按需要组合写作、实现和验证能力。

| 任务 | 参考 |
| --- | --- |
| 初始化或更新文档站脚手架 | [docs-site-bootstrap](../docs-site-bootstrap/SKILL.md) |
| 同步产品、设计、接口、数据库与运维事实 | [formal-docs-sync](../formal-docs-sync/SKILL.md) |
| 图文操作手册 | [manual-gen](../manual-gen/SKILL.md) |
| 站内发布说明 | [release-notes-gen](../release-notes-gen/SKILL.md) |
| 文档事实、链接与版本核对 | [docs-audit](../docs-audit/SKILL.md) |

根据任务使用宿主已有文档位置、模板和验证方式。独立文档与现有站点都可以交付；需要站点能力时使用脚手架资料。专业知识来源可以组合使用，授权持续适用。面向读者的长文可结合 human-writing 方法。

站点页面字段见 [frontmatter-contract.md](_internal/_shared/frontmatter-contract.md)。完成后提供文件或站点入口、验证结果及影响使用的限制。
