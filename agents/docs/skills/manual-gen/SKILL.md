# 图文操作手册

根据用户指定范围编写或更新手册。局部请求覆盖相应任务；完整手册覆盖当前产品的适用角色、主要入口与独立用户任务。目录按平台、业务场景和任务组织，并根据实际信息结构调整。

从已有环境、仓库运行说明和可用浏览器工具取得真实界面。明确环境与测试数据范围，在已有授权内完成必要的运行与采集。工具或访问不可用时说明缺少的证据，并继续可验证的内容。

阅读 [编写与验证方法](_internal/INSTRUCTIONS.md)。交付真实截图、可复现步骤、预期结果、异常处理以及页面覆盖和渲染检查结果。
