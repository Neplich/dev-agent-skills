# 正式文档同步

从本次变更或文档维护请求确定受影响事实，阅读现有页面及证据，完成授权范围内的更新。功能交付、部署验证、版本更新和已有系统回填均可直接使用本方法。

按读者任务选择产品、设计、API、数据库和运维资料。文档反映当前实现与验证状态；需要表达目标方案时明确其目标性质。普通文档沿用宿主格式，文档站页面采用已有 frontmatter、导航和 change-map。

阅读 [同步方法](_internal/INSTRUCTIONS.md) 及涉及的类型参考，更新正文、索引、引用和实际受影响映射，再执行适用的宿主检查。独立决策缺口和新增权限需要用户输入时说明具体事项。
