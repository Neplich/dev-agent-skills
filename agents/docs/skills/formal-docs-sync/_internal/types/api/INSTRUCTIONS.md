# API同步参考

对照 route、handler、schema、中间件和测试核对方法、路径、调用目的、鉴权、权限、参数类型、必填性、默认值、校验、成功响应与错误结构。流式、上传和下载接口还需说明内容类型、终止语义和相关头部。

按实际业务域、路由前缀与稳定维护边界组织页面。一个独立接口或紧密接口组可以形成叶子页，并从上级索引直接定位。已有 feature catalog 可帮助分类，代码与测试也可直接建立范围。

使用宿主 API 模板。新 API 页面默认 internal，面向外部开发者的任务按授权采用 public 或 both。保留既有公共页面的导航可达性。正文覆盖每个接口的请求、响应、错误、权限、示例和证据，更新页面与相应 change-map。
