# 管理工作区访问权限

## 适用范围

- 适用角色：工作区管理员
- 前置条件：使用测试账号 `test.user@example.invalid` 登录。

## 操作步骤

1. 打开目标工作区的“访问设置”。

   ![删除工作区确认框](./step-1-access-settings.svg)

2. 选择成员并保存权限。

   ![保存成员权限](./step-2-save-member.png)

## 预期结果

成员列表显示更新后的访问级别。

## 注意事项与异常处理

仅在测试工作区执行权限变更。
