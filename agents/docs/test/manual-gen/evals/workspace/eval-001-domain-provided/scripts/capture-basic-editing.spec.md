# Basic Editing and Preview Capture

## Task

Use the maintainer-provided anonymous environment to collect the runtime evidence needed for a basic editing and preview user guide.

## Coverage

- The user can locate and use the editing surface.
- The interface presents the resulting preview.
- The collected evidence is sufficient to document the confirmed workflow truthfully.

Keep generated screenshots and other runtime artifacts in the isolated run directory. Derive controls, interaction order, visible results, and capture names from the live interface rather than this task specification.
