# Export and Share Capture

## Task

Use the maintainer-provided anonymous environment to collect the runtime evidence needed for export and sharing user guidance.

## Coverage

- The available export interaction is documented from the live interface.
- The sharing interaction is documented without exposing its environment-specific identifier.
- The collected evidence supports a truthful, reproducible manual for the confirmed scope.

Keep generated screenshots and other runtime artifacts in the isolated run directory. Determine controls, interaction order, visible results, redaction method, and capture names during live exploration.
