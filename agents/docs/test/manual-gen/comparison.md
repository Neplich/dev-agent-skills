# manual-gen 评测结论

## 评测方式

`manual-gen` 不使用常规的合成 fixture、`with_skill` / `without_skill` lane 或独立 judge 评测。它的有效性依赖用户真实的已登录运行环境、对应源码仓库、当时可见的界面状态、实际截图和正式文档站渲染结果；脱离这些条件构造的常规 eval 无法可信复现任务，也容易把场景、协议或答案泄露给被测会话。

## 当前结论

- 常规 eval：不适用。
- 已确认价值：基于目前的真实使用结果，`manual-gen` 对从运行界面生成图文用户手册一定有用。
- 后续验证：由用户在真实项目中实际使用后检查手册范围、截图质量、图文对应、导航与可读性，并直接提出意见。
- 迭代依据：只根据真实使用中观察到的问题和用户反馈调整 skill，不把合成场景的通过率当作有效性证明。

## 评测资产策略

仓库不保留 `manual-gen` 的 `evals.json`、eval workspace、baseline、judge 结论、transcript 或运行期截图。真实使用过程中产生的临时采集与调试资产仍按宿主项目的安全和隐私要求处理，不作为本仓库的常规 eval 产物提交。
