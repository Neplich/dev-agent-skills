# Notification Center PRD

## Scope

Provide an in-product notification center where signed-in users can read their
notifications and distinguish unread items from items they have already seen.

## Acceptance criteria

- The notification list shows the current user's notifications newest first.
- Opening a notification marks it as read without changing other items.
- The empty state clearly explains that there are no notifications.

## Non-goals

- Email and push delivery are outside this change.
- Notification preference management is outside this change.
