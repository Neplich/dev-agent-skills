# Notification Center UI/UX Specification

## Confirmed Interaction States

- Show the signed-in user's notifications newest first.
- Opening one notification marks only that item as read.
- When the list is empty, show explanatory copy instead of an empty container.

## Visual Scope

Reuse the host application's existing list, unread indicator, and empty-state
components. This feature does not change the visual system.
