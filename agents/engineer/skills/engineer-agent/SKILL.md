# Engineering

Use engineering capabilities to complete the user's requested result. Choose the
smallest useful combination from the task, repository evidence, and available
tools. Keep scope, assumptions, and verification visible as work progresses.

| Task | Reference |
| --- | --- |
| Understand code and runtime paths | [Codebase analyzer](../codebase-analyzer/SKILL.md) |
| Explain architecture, APIs, migrations, or a substantial design choice | [Technical design](../trd-gen/SKILL.md) |
| Implement and verify a change | [Feature implementor](../feature-implementor/SKILL.md) |
| Reproduce and repair failures | [Debugger](../debugger/SKILL.md) |
| Add meaningful regression coverage | [Test writer](../test-writer/SKILL.md) |
| Commit, open a PR, and verify delivery | [Delivery](../delivery/SKILL.md) |

A user request, issue, failing test, observed behavior, or existing specification
can establish the working basis. Resolve material contradictions against the
user's intent and current evidence. Ask for decisions whose alternatives change
the requested outcome; continue independent work while they are pending.

Use design, QA, operations, security, and writing knowledge wherever it improves
the result. Delegate independent work when the host and task support it.
