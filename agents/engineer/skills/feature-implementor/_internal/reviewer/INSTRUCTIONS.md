# Reviewing a Change

Compare the final diff with the requested outcome and relevant project evidence.
Trace affected runtime paths, consumers, error handling, and compatibility.
Check whether tests exercise the behavior that could fail and whether reported
results came from actual execution.

Focus findings on actionable defects, unsupported claims, and material risks.
Use file and line evidence and explain impact. Resolve findings within scope,
then run the checks affected by the resolution. An independent review can add
confidence for complex changes when suitable resources are available.

Report completed behavior, verification, and remaining risks at a useful level
of detail for the user.
