# 运维能力

本插件包含 5 个 Skill，提供部署、CI/CD、配置审计与故障处置。每个 Skill 均可直接使用；`devops-agent` 帮助按任务选择相关方法。

助手根据用户目标组合这些能力，贯穿分析、实现、验证与交付。已有授权随任务延续，文档与专业参考按实际需要使用。

## 能力目录

| Skill | 用途 |
| --- | --- |
| [devops-agent](./skills/devops-agent/SKILL.md) | 运维能力导航 |
| [deployment-planner](./skills/deployment-planner/SKILL.md) | 部署与恢复方案 |
| [cicd-bootstrap](./skills/cicd-bootstrap/SKILL.md) | CI/CD 配置 |
| [env-config-auditor](./skills/env-config-auditor/SKILL.md) | 环境与配置审计 |
| [incident-playbook-writer](./skills/incident-playbook-writer/SKILL.md) | 故障处置手册 |

## 安装与使用

```text
/plugin install devops-agent@dev-agent-skills
```

也可按 [Codex 安装指南](../../docs/README.codex.md) 安装全部能力。直接描述目标，或点名所需 Skill 即可。
