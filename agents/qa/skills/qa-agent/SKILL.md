# Quality Assurance

Select test scope from the user's goal, changed code, reported failures, and
available product evidence. Reuse the repository's harness and persistent cases,
then extend coverage where the change creates meaningful risk.

| Task | Reference |
| --- | --- |
| Explore behavior and discover failures | [Exploratory testing](../exploratory-tester/SKILL.md) |
| Validate specified behavior | [Behavior-based testing](../spec-based-tester/SKILL.md) |
| Turn observations into reproducible defects | [Bug analysis](../bug-analyzer/SKILL.md) |
| Verify fixes and adjacent behavior | [Regression testing](../regression-suite/SKILL.md) |

For repeatable end-to-end work, use the existing test assets or these references:
[case format](./references/e2e-case-format.md),
[credential storage](./references/e2e-credential-store.md), and
[report format](./references/e2e-test-report.md).

Record what ran, the observed result, and the evidence. A user request, issue,
test, or reliable specification can establish expectations. Continue into repair
and documentation when those actions are within the task's authorization.
